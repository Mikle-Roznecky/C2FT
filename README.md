# C2FT (FTCFT)
Small python project for path input (as in terminals)
*Create by: Dov1ntc*

## Used Libraries:
- **itertools.chain** - fast work for list
- **sys, os, time** - base
- **msvcrt** - read byte input with keyboard
- **"decorators"** and **"tool"** - own functions
